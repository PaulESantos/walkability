# Modern Minimalist Cartographic Theme for Walkability

Clean theme optimized for geospatial network visualizations with
ggplot2.

## Usage

``` r
theme_walkability(base_size = 11, base_family = "", dark = TRUE)
```

## Arguments

- base_size:

  Base font size.

- base_family:

  Base font family.

- dark:

  Logical. If `TRUE` (default), uses a sleek dark theme. If `FALSE`,
  uses a clean white theme.

## Value

A `ggplot2` theme object that styles plot backgrounds, text, and legends
for walkability maps.
