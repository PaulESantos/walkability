# Plot Method for Walk Isochrone

Visualizes multi-threshold isochrone polygons with layered fills.

## Usage

``` r
# S3 method for class 'walk_isochrone'
plot(x, show_network = TRUE, ...)
```

## Arguments

- x:

  A `walk_isochrone` object.

- show_network:

  Logical. If `TRUE`, plots background street network.

- ...:

  Additional arguments.

## Value

A `ggplot` object.
