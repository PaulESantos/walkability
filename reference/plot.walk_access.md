# Plot Method for Walk Access

Visualizes the spatial distribution of accessible facilities from each
intersection.

## Usage

``` r
# S3 method for class 'walk_access'
plot(x, category = NULL, ...)
```

## Arguments

- x:

  A `walk_access` object.

- category:

  Character string of the category to display (if multiple exist).

- ...:

  Additional arguments.

## Value

A `ggplot` object.
